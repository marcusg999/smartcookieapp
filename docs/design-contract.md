# Design contract: "Saturday-morning cartoon", printed on concrete

Produced with /surprise-me. Direction #5 of 6 won the roll (seed 1795243789693009193).
The contract is fixed; renders are judged against it.

|                                           |                                                                                                                                                                                                                                                                                                                                                 |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Feeling**                               | Saturday-morning cartoons screen-printed on a concrete wall: joyful and loud for kids, confident and calm for the parent holding the phone.                                                                                                                                                                                                     |
| **Palette**                               | concrete `#D9D5CD` (page), paper `#F4F1EA` (surfaces), ink `#151311` (lines, text), safety orange `#FF5B14` (fills only, always with ink text), concrete-dark `#B9B4AA` (rules), muted ink `#4A4640` (secondary text). Allergy red `#C8102E` is reserved for allergy flags (CLAUDE.md §6) and never used decoratively.                          |
| **Type**                                  | Bodoni Moda (Didone, variable, italic for emphasis), huge and high-contrast, display ≥ 4.5rem on desktop. Source Sans 3 (humanist sans) for everything you read or tap. Scale ratio 1.333.                                                                                                                                                      |
| **Layout**                                | Broken asymmetric 12-column grid. One element per section deliberately crosses the gutter or overlaps its neighbour; cards tilt ±1–2°; hard 4px ink offset shadows instead of soft blur.                                                                                                                                                        |
| **Technique 1: broken grid**              | Hero (headline vs. tilted tray card), "This week" day strip (staggered heights and rotations), how-it-works comic panels, diagonal schools band.                                                                                                                                                                                                |
| **Technique 2: view transitions**         | React `<ViewTransition>`: day cards on the home page morph into the day cards on /menu; the logo persists across every page; page content slides and fades on navigation; switching menu days crossfades.                                                                                                                                       |
| **Technique 3: scroll-scrubbed sequence** | _Substitution:_ the roll asked for a Higgsfield clip, but the Higgsfield account has 0 credits. Per the skill's "don't fake it" rule, it's replaced by a hand-built SVG illustration sequence scrubbed by scroll: the lunch tray outline draws itself, food drops into each compartment, the cookie mascot pops up and a "PACKED!" stamp lands. |
| **Motion signature**                      | One slow WebGL shader field: concrete grain with drifting safety-orange halftone blobs, always moving, never fast. Static under `prefers-reduced-motion`.                                                                                                                                                                                       |
| **Assets**                                | Self-hosted Bodoni Moda and Source Sans 3 (variable woff2). Hand-authored SVG cartoon set (tray, pasta, broccoli, apple, carrots, wrap, cookie mascot). No emoji, no stock photos, no CSS-gradient stand-ins.                                                                                                                                   |
| **One unmistakable moment**               | Scrolling the hero packs the lunch tray compartment by compartment, then the cookie mascot pops up winking as a crooked orange PACKED! stamp lands.                                                                                                                                                                                             |
| **Out of scope**                          | Dark mode; an admin redesign beyond the shared tokens; real menu data (the /menu page uses clearly marked demo meals until the menu phase); sound.                                                                                                                                                                                              |
| **Non-negotiables kept**                  | WCAG AA contrast, keyboard and focus states, 375px layout, nonce CSP (no inline scripts), reduced-motion fallbacks, every interaction still one obvious tap.                                                                                                                                                                                    |

## Audit log (screenshot, then critique, then fix)

Bar: oatly.com's homepage (a playful, illustrated, type-led brand site), compared blind at 1440px and 375px.

1. **Pass 1.** Mobile hero overflowed the sticky viewport, so the headline was hidden under the header. The schools band shader washed the ink to grey. The wrap read as a toilet roll and the macaroni as shrimp. Fixed with a header-height-aware sticky stage, a transparent shader mode, and redrawn art.
2. **Pass 2.** Fixed a stale Turbopack CSS cache (clean build). "How it works" was the weakest section (grey boxes, colliding numerals), so it became a three-panel comic strip in orange, paper and ink with speech bubbles. Added a favicon to stop a console 404.
3. **Pass 3.** Halftone dots sat behind the orange "whole class?" heading and the mobile hero copy. Masked the shader away from text; centred the orphaned Friday card.
4. **Pass 4.** Contrast audit: orange link text on paper (2:1) became ink with a 3px orange underline; fixed button variants that hadn't applied. Verified the reduced-motion fallback (finished tray, no scroll track) and zero console errors.
